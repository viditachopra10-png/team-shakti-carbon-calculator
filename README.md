# 🌱 Digital Carbon Footprint Calculator

A simple and interactive website that helps users estimate their household carbon footprint based on daily lifestyle choices.

## 🌍 About The Project

This project creates awareness about carbon emissions caused by:
- Transportation
- Electricity usage
- Air conditioning
- Cooking fuel
- Generator usage

The calculator provides an approximate CO₂ emission result and encourages users to adopt sustainable habits.

## 🚀 Features

- Responsive design for mobile and laptop
- User-friendly questionnaire
- Instant carbon footprint calculation
- Eco-friendly interface
- No data storage required

## 💡 Purpose

To spread awareness about climate change and motivate people to reduce their carbon footprint.

Made for sustainability awareness 🌱
